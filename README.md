### 📦 Sanchay AI: Smart Inventory & Demand Forecasting
*ML-driven inventory planning that helps prevent stock-outs.*

- Forecasts **time-to-stockout with confidence intervals** and auto-calculates **reorder points and order quantities at a 95% service level**.
- Decision dashboard with a **supplier-delay simulator (1–90 day scenarios)**, critical and low-stock alerts, and live inventory valuation.
- Live public demo on GitHub Pages in **two modes**: server-backed and fully standalone in the browser.

### 🪑 [ExamSeat](https://github.com/rikhil-33/ExamSeat): Exam Seating Allocation Platform
*Replaces manual exam seating with instant, conflict-free assignment.*

- **Student portal:** hall-ticket lookup returns a seat in one step. Lookups are idempotent, so resubmitting an ID always returns the same seat (zero duplicate allocations).
- **Admin dashboard:** real-time room grid with occupancy stats and student-to-seat mapping, refreshed every 5 seconds.
- **Smart allocation:** random assignment from a global seat pool, with the university's one-chair buffer rule enforced by restricting allocation to odd-numbered seats.
- **Stack:** `Python` `Flask` `JavaScript` `Jinja2` `CSS`
